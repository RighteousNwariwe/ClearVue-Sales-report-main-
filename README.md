# ClearVue Sales Report System

A modern, enterprise-grade sales reporting system built for ClearVue Ltd. This project demonstrates a comprehensive full-stack solution for real-time sales analytics, data integration, and business intelligence visualization.

## 🎯 Project Overview

The ClearVue Sales Report System is a **production-ready analytics platform** that processes, aggregates, and visualizes sales data at scale. By combining multiple data technologies, this system provides real-time insights into business performance through an interactive Power BI dashboard.

### Key Highlights
- **Real-time Data Streaming**: Kafka-based pipeline for live data ingestion
- **Multi-Database Architecture**: SQL + MongoDB for scalable data storage
- **Advanced Analytics**: Custom Power BI dashboard with actionable insights
- **Enterprise Design**: Built following industry best practices for data engineering and business intelligence

---

## 🛠 Technology Stack

| Technology | Purpose | Use Case |
|-----------|---------|----------|
| **SQL (PostgreSQL/MySQL)** | Relational data storage | Structured sales transactions, customer data |
| **MongoDB** | NoSQL database | Flexible document storage, event logs |
| **Apache Kafka** | Event streaming platform | Real-time data ingestion, event processing |
| **Power BI** | Business intelligence & visualization | Interactive dashboards, data analysis |

---

## 📊 Architecture & Components

### 1. **Data Ingestion Layer**
- Apache Kafka brokers consume real-time sales events
- Multiple data sources feed into the pipeline
- Event-driven architecture ensures low-latency processing

### 2. **Data Storage Layer**
- **SQL Database**: Normalized schema for transactional consistency
- **MongoDB**: Document-based storage for flexible data models
- Optimized for both OLTP and OLAP workloads

### 3. **Analytics & Reporting Layer**
- Custom Power BI dashboards
- Real-time KPI tracking
- Drill-down analytics for granular business insights
